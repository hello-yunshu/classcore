# Shared Capability Promotion Rules

## Rule 1 — First use stays local

第一次出现的能力默认留在 Lesson。

## Rule 2 — Second lesson proves reuse

第二节课也需要时：
- 比较接口；
- 比较生命周期；
- 比较状态；
- 比较错误语义。

只有真正一致才抽 Shared。

## Rule 3 — Core is infrastructure

只有跨课型、跨学科都需要，而且与业务语义无关，才进入 Core。

## TransformBoard

本轮允许它成为 Shared 的前提：
- 所有 puzzle-specific data 可配置；
- engine 不知道笑脸/四碎片；
- event schema 是几何通用语义；
- no lesson IDs；
- 下一种几何拼图可复用。

否则先留在 Lesson。
