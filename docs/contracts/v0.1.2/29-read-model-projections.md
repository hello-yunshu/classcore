# Read Model & Projection Principle v0.1.2 / CR2

Canonical write-side state remains Server-owned. No browser Surface queries raw storage or Server-only Identity Directory.

Surface projections:
- Student: own state/advice + self identity only.
- Teacher Runtime: identifiable classroom/decision projection.
- Observer: session-pseudonymized read-only research projection.
- Display: session-pseudonymized projected Stage only; same subject IDs as Observer.
- Backstage: operations projection including authorized roster fields.
- Authoring Studio: no real classroom student identity; placeholders/synthetic preview only.
- Simulation/Rehearsal: synthetic projections only.

Canonical `StageState` is never a public wire response. Teacher/Observer/Display receive `ProjectedStageState` generated by explicit content projectors.

Read models are disposable/rebuildable and are not canonical history.
