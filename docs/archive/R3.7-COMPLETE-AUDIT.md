# R3.7 完整审计 — Validation Closure / Codex Mother Package

> 日期：2026-09-10  
> Foundation：v0.1.2（冻结不变）  
> Roadmap：R3.7  
> Correctness：CR8

## 结论

R3.7 的目标不是继续扩架构，而是把 R3.6 审计发现的“验证器假绿灯”与交接缺口收口。Foundation 领域模型继续保持冻结；本轮修改集中在 Lesson Package semantic gate、Foundation exact-set freeze、模板安全、工具链复现、ARM64 CI 与 Docker 发布边界。

R3.7 可以作为后续 Codex 开发的唯一母包。它仍然不是 D7 课堂 RC，也不应被描述为已经完成真实 Apple Silicon + XP21A 教室演练。

## 已关闭的高优先级问题

1. **Lazy asset 漏检**：所有 Lesson asset 都必须真实存在；`preload` 只影响 size/hash 的必填条件。
2. **Capability 漏检**：Applet instance 的 `requiredCapabilities` 必须是 Manifest `capabilities` 的子集。
3. **事件权威边界漏检**：Applet 不能声明服务端保留事件前缀。
4. **Presentation 跨文件断链与可移植性**：`deckId`、`sceneId` 与 `presentationRuntime` 在通用 Lesson Gate 中强制校验；重复 `sceneId` / `bindingId`、绑定参数硬编码真实参与者身份也会失败。
5. **路径逃逸**：package、optional、schema、asset 引用同时做 lexical containment 与 existing-target realpath containment，普通 `../` 和 symlink 逃逸都不得离开 Lesson Package 根目录。
6. **Foundation freeze 只校验已登记文件**：改为 exact-set；新增未登记 Foundation 文件也会失败。
7. **`lesson:new` 字符串注入**：JSON 文件改为 parse → 结构化替换 → stringify，标题中的引号、反斜杠和 Unicode 安全。
8. **ARM64 只在文档里要求**：CI 增加原生 `ubuntu-24.04-arm` full-check 与原生 ARM64 Docker build。
9. **Docker root runtime**：runtime stage 改为 `USER node`，`/data` 赋予 node 用户权限。
10. **LAN Gate 语义混淆**：自动 Docker Gate 只声明 host LAN-interface probe；真实路由器 + XP21A 单独作为 D7 人工硬 Gate。

## 仍然保留的正确边界

- Apple Silicon / `linux/arm64` 是本次公开课 P0；`linux/amd64` 为兼容目标。
- Node 24.21.0 LTS / npm 11.19.0 / TypeScript 7.0.2 保持当前正式基线。
- Python `jsonschema` 只用于开发/CI，不进入课堂 runtime image。
- Student 弱端只承担轻量网页交互；复杂计算、分析与汇总留在 Mac 后端。
- Observer/Display 只读；Teacher Control 与 Student durable 路径优先于 Observer 流量。
- 前端视觉与 Design System 尚未冻结，当前 Web Shell 不能被当作正式 UI。

## 本轮明确不做、且不阻断 R3.7 的事项

以下不是遗漏，而是基于当前“开发母包而非冻结课堂 RC”的主动取舍：

- Docker 基础镜像继续锁定精确 Node/发行版 tag，而不在开发母包阶段锁死 image digest；最终 D7 RC 可记录实际 image digest，避免开发期错过基础镜像安全修订。
- GitHub Actions 当前使用官方 action 的稳定 major tag；在组织未来需要更严格供应链策略时再切换到 commit SHA + 自动更新机制，避免当前维护成本超过收益。
- toolchain 版本仍同时出现在 `.nvmrc`、`.node-version`、`package.json`、CI 与 Docker，但 `config/toolchain.json` + machine check 会阻止这些副本静默漂移；暂不引入代码生成层。
- `npm audit` 不作为当前课堂 runtime Gate：当前生产 runtime 没有新增第三方 npm 业务依赖；一旦接入真实 Presentation Engine/前端依赖，应重新启用依赖漏洞与 license/SBOM 审计。

这些事项应在 D7 RC 冻结或真实第三方依赖进入主路径时重新审计，而不是继续扩张 Foundation。
