# R3.9 完整审计 — CR10 Final Corrective Validation Closure

> Foundation：v0.1.2（继续冻结）

## 结论

R3.9 不扩 Foundation，只修 R3.8 独立攻击性审计发现的身份隐私与名单准备层 fail-open。当前母包可作为后续 Codex 开发基线，但“开发母包可交付”和“D7 课堂 RC 可上课”仍严格分开。

## 本轮关闭的问题

1. Private Identity Guard 递归语义完整化：字符串、数组、对象 key、对象 value、任意嵌套统一检查，并从只扫 `source.parameters` 提升为扫描完整 ClassroomWidgetBinding。
2. 身份引用词表补齐 `roster:` 与 `class:`，并将明确的连接/认领敏感字段（device/client instance/hint/reconnect/access token/credential）纳入公共输出 fail-closed。
3. `config/private-identity-mutation-corpus.json` 成为 TS Runtime / JS Lesson Validator / Python Validator 的共同反例语料。
4. `duplicate-participant-id` 从不可触发分支修正为真正的重复行计数。
5. Student Claim 与 roster preflight 共用 trim 语义，空白 hint fail closed。
6. `StudentProjectionService.forPublic()` 不再为不存在的学生生成幽灵 pseudonym；底层 pseudonym directory 也拒绝非 `student:` participant。
7. 新增 `workspace:check`，将内部依赖存在性、声明完整性和无环从人工审计转为机器 Gate。
8. 自审计新增 D7 Product Readiness hard blocker：已知产品链未完成时 `release:d7` 不可能误绿；reference Server 源码默认 loopback-only。
9. Transport 幂等增加 canonical payload 一致性：相同 ID + 相同语义 payload 可重试，相同 ID + 冲突 payload 明确失败。

- 当前 reference WebSocket Server 仍是 transport/storage vertical slice，不是已认证的课堂 Server；正式课堂必须接入 credential → membership → AuthenticatedConnectionContext → AuthorizationService。
- TransformBoard 正式 Student UI、真实 Presentation Engine/Studio、Join/Presence/Submission/Artifact、正式 Teacher/Observer/Display 交互仍属于产品开发阶段。
