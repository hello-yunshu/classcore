## R3.7 二次攻击性审计问题关闭情况

1. Lesson 只扫描一级目录 → **已关闭**：递归发现 `examples/`、`lessons/` 下所有 package root；symlink 与 package-in-package 歧义 fail closed。
2. Presentation/Projection 身份名单漂移 → **已关闭**：`config/private-identity-policy.json` 为单一配置源；JS/Python validator 直接读取，TypeScript Guard 由该配置生成并有 parity test。字段覆盖姓名、seat/class/roster、participant/student/membership/connection 等稳定内部身份字段及对应稳定引用前缀。
3. Teacher Submission/Artifact 无 scope → **已关闭**：Authorization 在角色分支前要求显式 scope context。
4. Docker local-tools 泄漏断言可能被 catch → **已关闭**：LAN probe 抽成可注入测试的 helper，真实反例会抛 `SECURITY_ASSERTION_FAILED`。
5. `release:check` 不强制 Apple Silicon → **已关闭语义歧义**：保留跨架构 `docker:gate/release:check`，新增 Apple-Silicon-only `release:d7`。
6. 幂等键 `|` 拼接碰撞 → **已关闭**：改为 JSON tuple 编码并加入构造碰撞反例。
7. Controller Lease helper 可被 Student 直接调用 → **已关闭**：claim/renew/takeover/release 均 Teacher-only fail closed。
8. CR3 内部文档引用断链 → **已关闭**：补兼容说明，`docs:check` 将其列为 canonical doc。
9. 根 `SHA256SUMS` 未进入机器 Gate → **已关闭**：新增 exact-set `integrity:generate/integrity:check`，`release:check` 强制校验。
10. Compose 只被字符串检查 → **已增强**：通用 Docker Gate 先执行 `docker compose ... config --quiet`；`release:d7` 另执行真实 Compose up/down 部署入口 Gate。
